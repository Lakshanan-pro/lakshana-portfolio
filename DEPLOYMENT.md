## 🚀 Hosting Options

### 1. GitHub Pages (FREE & EASY)

**Steps:**
1. Go to: https://github.com/Lakshanan-pro/Portfolio/settings/pages
2. Under "Source", select **`main`** branch
3. Click **Save**
4. Wait 1-2 minutes
5. Your site will be live at: **`https://lakshanan-pro.github.io/Portfolio/`**

**That's it!** No build, no configuration needed!

### 2. Netlify (FREE)

**Drag & Drop:**
1. Go to: https://app.netlify.com/drop
2. Drag the `/home/user/portfolio-html` folder
3. Done! Live instantly with custom domain option

**Or connect GitHub:**
1. Go to: https://app.netlify.com
2. Click "Add new site" → "Import from Git"
3. Select your Portfolio repository
4. No build command needed!
5. Deploy!

### 3. Vercel (FREE)

1. Go to: https://vercel.com/new
2. Import your Portfolio repository
3. No configuration needed
4. Deploy!

### 4. Any Static Host

Just upload these files to your web server:
- index.html
- app.js
- styles.css
- images/
